Foundation 01

Vectors → Single Score: The Fundamental Shift

Why do we multiply and sum elements?

Vector Arithmetic vs Dot Product

Vector Addition / Subtraction takes two vectors and moves you to a brand new coordinate in space (\(\vec{A} \pm \vec{B} = \text{Vector}\)).

The Dot Product takes two vectors and collapses them into a single scalar number (\(\vec{A} \cdot \vec{B} = \text{Float}\)). It tells you: how much do these two vectors agree with each other?

The Element-by-Element Multiplication Rule

$$\vec{A} \cdot \vec{B} = \sum_{i=0}^{n-1} A_i B_i = A_0 B_0 + A_1 B_1 + \dots + A_{n-1} B_{n-1}$$

Each dimension is tested independently. When two vectors agree on a trait (both positive or both negative), the product is positive. When they disagree (one positive, one negative), the product is negative.

Walkthrough of the Assignment Example

Vector 1: [0.8, 0.5, 0.5]  |  Vector 2: [0.5, 0.4, 0.6]

Dimension 0:
\(0.8 \times 0.5 = \mathbf{0.40}\)
Dimension 1:
\(0.5 \times 0.4 = \mathbf{0.20}\)
Dimension 2:
\(0.5 \times 0.6 = \mathbf{0.30}\)

Total Sum: \(0.40 + 0.20 + 0.30 = \mathbf{0.90}\)

Foundation 02

The Geometric Lens: Shadows and Angles

Understanding \(\vec{A} \cdot \vec{B} = \|\vec{A}\| \|\vec{B}\| \cos(\theta)\)

\(\theta = 0^\circ\) (Same Direction)

\(\cos(0^\circ) = +1\)

The vectors point in the exact same direction. The shadow is maximal. Produces the highest possible positive similarity score.

\(\theta = 90^\circ\) (Orthogonal)

\(\cos(90^\circ) = 0\)

The vectors are perpendicular. Vector A casts zero shadow onto Vector B. Dot product is exactly 0 (completely unrelated concepts).

\(\theta = 180^\circ\) (Opposite)

\(\cos(180^\circ) = -1\)

The vectors point in opposite directions. The shadow points backwards. Produces a strong negative penalty score.

Implementation Guide 05

Algorithmic Blueprint for dot()

Translating the mathematical summation into clean Python code.

The 3 Core Steps

1. Guard Clause
If len(vec1) != len(vec2), raise a ValueError.
2. Scalar Accumulator
Initialize total = 0.0 (not a list, because the dot product is a single number).
3. Loop & Multiply-Accumulate (MAC)
For each index i, add vec1[i] * vec2[i] to total.

Conceptual Code Flow

def dot(vec1: list[float], vec2: list[float]) -> float: # 1. Guard against mismatched dimensions if len(vec1) != len(vec2): raise ValueError("Vectors must have the same length") # 2. Accumulator for the running sum total = 0.0 # 3. Multiply matching pairs and accumulate for i in range(len(vec1)): total += vec1[i] * vec2[i] return total

Question: If vector \(\vec{A} = [1.0, 0.0]\) and \(\vec{B} = [0.0, 1.0]\), what is their dot product, and what does it mean?
A) 1.0 — they are identical vectors
B) 0.0 — they are perpendicular (orthogonal), meaning they share zero similarity
C) -1.0 — they cancel each other out completely
Correct! \((1.0 \times 0.0) + (0.0 \times 1.0) = 0.0\). In 2D space, \([1, 0]\) is the X axis and \([0, 1]\) is the Y axis ($90^\circ$ angle). Since $\cos(90^\circ) = 0$, orthogonal concepts have zero correlation!
