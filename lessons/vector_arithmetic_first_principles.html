Foundation 01

What is a Vector, Really?

Three lenses of understanding: Physics, Computer Science, and Latent Semantic Space.

1. The Physics Lens

A directed displacement arrow.

A vector has a direction and a magnitude (length). It represents a step or motion from a starting coordinate to a destination in space.

2. The CS Lens

An indexed list of numbers.

Computationally, a vector is simply a 1D array of floats [x₀, x₁, ..., xₙ₋₁] of fixed length \(N\). Each slot holds a scalar value.

3. The Semantic Lens

A point in "Meaning Space".

In modern AI and search, every dimension corresponds to a latent semantic feature (e.g. Animation-ness, Dark Humor, Royalty, Urgency).

The Core Intuition: Independent Axes of Meaning

When an embedding model embeds a concept into an \(N\)-dimensional space, each axis represents an orthogonal (independent) property. Because the axes are independent, what happens on dimension 1 does not affect dimension 2 or dimension 3. This is why vector math operates element-by-element (component-wise)!

$$\vec{v} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix} = v_1 \mathbf{\hat{e}}_1 + v_2 \mathbf{\hat{e}}_2 + \dots + v_n \mathbf{\hat{e}}_n$$
Foundation 02

Vector Addition: The Principle of Superposition

Combining Concepts — "I want something that has traits of THIS and traits of THAT."

1. The Geometric Rule: "Tip-to-Tail"

To add vector \(\vec{B}\) to vector \(\vec{A}\), you place the tail of \(\vec{B}\) at the tip (arrowhead) of \(\vec{A}\).

The resulting sum \(\vec{C} = \vec{A} + \vec{B}\) is the brand-new arrow drawn directly from the origin (tail of \(\vec{A}\)) to the final destination (tip of \(\vec{B}\)).

This forms the classic Parallelogram Law: traveling along \(\vec{A}\) then \(\vec{B}\) reaches the exact same point as traveling along \(\vec{B}\) then \(\vec{A}\) (\(\vec{A} + \vec{B} = \vec{B} + \vec{A}\), commutativity).

2. The Algebraic Rule: Element-wise Sum

Because each dimension is independent, we simply add matching indices together:

$$\vec{A} + \vec{B} = \begin{bmatrix} A_0 + B_0 \\ A_1 + B_1 \\ \vdots \\ A_{n-1} + B_{n-1} \end{bmatrix}$$
"The Great Bear" (Animation, Adventure) [ 0.5, -0.2, 0.8 ]
+ "Back Country" (Horror, Thriller) [ 0.1, 0.9, -0.3 ]
= Combined Concept [ 0.6, 0.7, 0.5 ]

Why does the semantic meaning blend?

Notice the numbers in the combined concept above:

  • Dimension 0 (Animation/Family): \(0.5 + 0.1 = 0.6\) → Retains strong animated/family warmth.
  • Dimension 1 (Horror/Dark): \(-0.2 + 0.9 = 0.7\) → Shifts from anti-horror (\(-0.2\)) into decidedly spooky territory (\(0.7\)).
  • Dimension 2 (Wilderness/Survival): \(0.8 + (-0.3) = 0.5\) → Balances the survival intensity.

The resulting vector points directly toward the cluster of movies that are both Animated/Family and Spooky/Horror (like Coraline or Monster House)!

Foundation 03

Vector Subtraction: The Displacement Vector

Removing Concepts & Steering — "I want THIS, but without THAT."

How to Visualize Subtraction

There are two equivalent ways to understand \(\vec{C} = \vec{A} - \vec{B}\):

Method 1: Invert and Add (\(\vec{A} + (-\vec{B})\))
Flip vector \(\vec{B}\) 180° around the origin so it points in the opposite direction (\(-\vec{B}\)), then apply the tip-to-tail addition rule.
Method 2: The Direct Gap (Tip of B → Tip of A)
Ask yourself: "What vector must I add to \(\vec{B}\) to reach \(\vec{A}\)?" (\(\vec{B} + \vec{X} = \vec{A} \implies \vec{X} = \vec{A} - \vec{B}\)). It is the arrow pointing from the head of \(\vec{B}\) directly to the head of \(\vec{A}\).

Algebraic Difference & Negative Steering

Subtracting elements at identical indices:

$$\vec{A} - \vec{B} = \begin{bmatrix} A_0 - B_0 \\ A_1 - B_1 \\ \vdots \\ A_{n-1} - B_{n-1} \end{bmatrix}$$
"The Great Bear" (Animation, Family) [ 0.5, -0.2, 0.8 ]
- "The Revenant" (Gore, Survival Horror) [ 0.1, 0.9, -0.3 ]
= Filtered Concept [ 0.4, -1.1, 1.1 ]

Notice index 1: \(-0.2 - 0.9 = -1.1\). The negative component actively repels horror results during cosine search!

Implementation Guide 06

First-Principles Algorithmic Thinking

Translating the mathematical laws into clean, robust code.

1. The Invariants (Rules That Must Hold)

  • 1

    Dimensional Compatibility

    You cannot add a 3D vector to a 4D vector. Vectors must inhabit the exact same space (\(\mathbb{R}^n\)). Always verify len(vec1) == len(vec2) first.

  • 2

    Immutability & Pure Functions

    Vector operations should produce a fresh new vector list, leaving the original input vectors intact and unmutated.

  • 3

    Commutativity vs Non-Commutativity

    Addition is commutative: \(A + B = B + A\). Subtraction is order-dependent: \(A - B \neq B - A\) (in fact, \(B - A = -(A - B)\)).

2. Conceptual Execution Flow

Below is a conceptual trace of how an element-wise vector accumulator moves through memory:

# Conceptual Steps for Vector Addition / Subtraction: 1. Check: len(vec1) != len(vec2) → raise descriptive error 2. Initialize an empty result collector: result = [] 3. Loop over index i from 0 to len(vec1) - 1: a. Compute scalar sum or difference: vec1[i] ± vec2[i] b. Append scalar result to result 4. Return result
💡 Why not use NumPy in our assignment?

While production systems use optimized C/BLAS libraries like NumPy (a + b), building these functions from scratch with pure Python lists and loops ensures you deeply internalize index iteration, pointer indexing, and memory allocation patterns!

Question 1: If vector \(\vec{A} = [2.0, -1.0]\) and \(\vec{B} = [2.0, -1.0]\), what is the geometric meaning of \(\vec{A} - \vec{B}\)?
A) A vector pointing twice as far in the same direction: [4.0, -2.0]
B) The zero vector [0.0, 0.0] representing zero displacement (you are already at the destination)
C) An error because vectors cannot be subtracted from themselves
Correct! \(\vec{A} - \vec{A} = [2-2, -1 - (-1)] = [0, 0]\). Geometrically, the distance and displacement required to travel from \(\vec{A}\) to \(\vec{A}\) is zero!
Question 2: What happens if you try to add a 384-dimensional MiniLM embedding to a 768-dimensional BERT embedding?
A) The computer fills the missing 384 dimensions with zeros and adds them
B) It calculates the dot product instead of addition
C) It is mathematically invalid because the two spaces have different basis dimensions, so a length error must be raised
Correct! Vector spaces of different dimensions cannot be combined with standard element-wise addition because their coordinate axes do not correspond to the same basis features.
